面向空中操作策略自进化的
模拟学院

A Simulated Academy for Self-Improving Aerial Manipulation

视觉—物理一致性闭环学习基础设施策略自进化Sim-to-Real 验证

摘要

空中操作策略需要协调飞行运动与环境交互；有用的练习既须能可靠重现并获得监督，也须能回应当前策略的学习需求。本文提出 AirSpark：面向空中操作策略自进化的模拟学院，将 Unreal Engine 渲染、MuJoCo 动力学、场景与机器人配准、自动经验生成、训练和评价连接为统一设施。SparkMentor 以 Agent Harness 组织这些工具，结合执行诊断与跨轮学习反馈，在预定范围内修订监督起点、经验构成和回放配置；学生通过参数更新保留所学能力。过程条件分配提供初始参考规则。研究设计在至少两个任务上比较固定方案、规则式修订、当前反馈与历史反馈修订，并以等预算原生补采对照检验学院经验的价值。最终冻结学生，在原生 AM-Bench 与对应真实机器人任务中分别评价；真实场景采用 3DGS 外观重建与显式物理配准。本文提出平台和有界反馈自进化框架，定量收益与真实迁移结论由预定实验检验。
