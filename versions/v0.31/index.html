AirSpark

面向空中操作策略自进化的
模拟学院

A Simulated Academy for Self-Improving Aerial Manipulation

视觉—物理一致性闭环学习基础设施策略自进化Sim-to-Real 验证

摘要

空中操作拓展了机器人的三维作业空间，视觉动作策略为自主抓取与接触作业提供了学习途径。然而，机载视角随飞行运动变化，飞行基座、机械臂与环境之间存在动力学耦合，操作结果不仅取决于相对位姿，还受到接近速度与接触时机的影响。策略的执行偏差可能使其进入示范覆盖不足的交互状态，而在真实环境中反复获取相应经验与监督成本较高。为支持可重复的空中交互练习，并依据策略表现与实际学习效果组织多轮改进，本文提出 AirSpark，一套面向空中操作策略自进化的模拟学院。学院结合 Unreal Engine 视觉渲染与 MuJoCo 动力学仿真，集成可配置任务、可重复交互、视觉—物理同步记录、自动监督生成及训练评测，并通过真实场景重建与物理配准支持对应任务的仿真练习。SparkMentor 作为具有跨轮记忆的 Agent Harness，依据分阶段执行诊断组织针对性练习与策略训练，通过参数更新实现跨轮学习，并结合历史干预记录和实际学习效果修订后续计划。我们设计学院运行可靠性评估、预算匹配的多轮学习与数据来源对照，以及冻结策略的原生 AM-Bench 回测和对应物理实机评价，以检验学院设施的可靠性、反馈自进化的完整任务学习收益及所得能力的外部有效性。
