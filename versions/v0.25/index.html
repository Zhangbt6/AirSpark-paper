AirSpark

面向空中操作策略自进化的
模拟学院

A Simulated Academy for Self-Improving Aerial Manipulation

视觉—物理一致性闭环学习基础设施策略自进化Sim-to-Real 验证

摘要

空中操作拓展了机器人的三维作业空间，视觉动作策略为自主抓取与接触作业提供了学习途径。然而，飞行和机械臂运动会改变机载视角，接触又会反过来影响机体运动，使策略需要协调视觉判断、运动状态和动作时机。实际执行中的位置、速度或接触变化，可能暴露出既有训练尚未充分解决的动作协调与阶段衔接问题。本文研究如何根据策略的执行表现和训练后的能力变化安排后续练习，支持空中操作策略的多轮改进。围绕这些需求反复开展真实试验、获取监督并检验更新，又受到执行、复位与监督成本的限制。为此，我们提出 AirSpark，一套面向空中操作策略自进化的模拟学院。学院结合高保真视觉渲染与动力学仿真，将可配置场景、可重复交互、自动监督生成及训练评测组织为共享学习设施，并通过真实场景重建与物理配准支持对应任务的仿真练习。SparkMentor 作为结合跨轮记忆的 Agent Harness，根据策略执行证据组织针对性练习与学生参数更新，再利用实际学习效果修订后续改进计划。实验以同预算的固定采集训练流程为主要对照，结合学院运行可靠性、原生 AM-Bench 回测与冻结策略的物理实机执行，检验反馈自进化的学习效用及所得能力的外部有效性。
