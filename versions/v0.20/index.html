A Simulated Academy for Self-Improving Aerial Manipulation

视觉—物理一致性闭环学习基础设施策略自进化Sim-to-Real 验证

摘要

空中操作策略需要协调飞行运动与物理交互，而接触和载荷转换等经验的获取、监督与复验仍依赖完整的实验设施。本文提出 AirSpark：面向空中操作策略自进化的模拟学院，将 Unreal Engine 视觉渲染、MuJoCo 动力学、场景配置、自动采集标注与策略训练评价连接为统一平台。SparkMentor 根据当前执行证据和跨轮干预记录组织后续学习；过程条件分配作为参考方法，通过合法物理前缀与专家延续生成经验，再更新并验收学生策略。学习反馈支持在代表任务上比较有限的经验生成与使用配置。研究设计分别检验平台执行与监督可靠性、匹配预算下的策略收益，以及冻结模型在原生 AM-Bench 和 3DGS 对应真实任务中的表现。AirSpark 为反馈驱动的空中操作学习提供可追溯、可复用的实验基础。
