AirSpark

面向空中操作策略自进化的
模拟学院

A Simulated Academy for Self-Improving Aerial Manipulation

视觉—物理一致性闭环学习基础设施策略自进化Sim-to-Real 验证

摘要

空中操作要求视觉动作策略在变化的机载视角下协调飞行、机械臂运动与环境交互。真实任务中的经验获取、环境复位和监督成本，使策略难以围绕自身能力缺口反复练习。本文提出 AirSpark，一套面向空中操作策略自进化的模拟学院。学院结合 UE 视觉渲染与 MuJoCo 动力学，通过场景构建与真实场景配准、可重复任务执行、自动数据采集与标注，以及统一训练和评价接口，支持可追溯的学习过程。在此基础上，SparkMentor 作为 Agent Harness，组织策略执行、交互过程诊断、反馈驱动练习规划、专家监督生成、学生策略更新和学习评估与接纳。执行证据用于发现能力缺口，跨轮记忆与学习反馈用于调整后续练习，学习结果通过参数更新保留于学生策略。研究以学院设施可靠性、同预算下相对固定采集训练流程的学习效用，以及冻结学生的原生 AM-Bench 回测和物理实机执行为三组检验，评价模拟学院能否支持可验证的空中操作能力改进。当前为方法与实验设计，定量结论由后续实验确定。
