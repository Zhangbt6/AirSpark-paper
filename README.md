# AirSpark paper design v0.36

Public research design for AirSpark: A Simulated Academy for Self-Improving Aerial Manipulation.

- Primary student: DP. Tasks: Lemon Harvesting and Push Slider in UE + MuJoCo.
- Three paired chains, two updates per setting; fixed practice and feedback-guided practice.
- Lemon controls: rule allocation and no cross-round history.
- Real study: initial, reconstructed-scene fixed practice, reconstructed-scene full practice.
- 8 incremental settings, 24 chains, at most 48 candidate trainings.
- Benchmark sealed tests: 1,000 episodes. Real-line simulation: 210 episodes. Real tests: 90.
- Collection, development tests, initial training and pilots are additional.
- Mentor proposes bounded condition allocations; the server validates feasibility and resources.
- Full expert demonstrations are primary. Suffix tools require pilot qualification.
- Weight warm-starting resets optimizer state. Numeric budgets and acceptance thresholds await pilot registration.
- ACT, native benchmark return and experience reuse are extensions.
- Quantitative results remain unmeasured.
